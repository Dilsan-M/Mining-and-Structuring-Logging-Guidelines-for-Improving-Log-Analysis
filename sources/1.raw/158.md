# HTTP Load Balancer with Hyper

## Notes

We are going to create a complete, configurable HTTP load balancer with the following features:

## Key Features:

1. **Generic Load Balancing Interface**: The `LoadBalancingStrategy` trait allows easy extension with new strategies
2. **Round Robin Implementation**: Current implementation with proper state management
3. **JSON Configuration**: Routes, backends, and settings are configurable via `config.json`
4. **Comprehensive Tracing**: Request tracing with unique IDs, timing, and structured logging
5. **Middleware Chain**: Extensible middleware system for logging, rate limiting, auth, etc.
6. **Route Matching**: Intelligent path-based routing with longest-match preference

## Configuration Structure:

The system uses a `config.json` file with this structure:

```json
{
  "server": {
    "bind_address": "127.0.0.1:3000",
    "timeout_seconds": 30
  },
  "routes": {
    "api": {
      "path": "/api",
      "backends": [
        {
          "url": "http://127.0.0.1:8001",
          "weight": 1,
          "health_check_path": "/health"
        }
      ],
      "load_balancing": {
        "strategy": "round_robin"
      }
    }
  }
}
```

## Project Structure:

- `src/main.rs`: Entry point and server setup
- `src/config.rs`: Configuration management with JSON serialization
- `src/load_balancer.rs`: Core load balancing logic with strategy pattern
- `src/middleware.rs`: Middleware chain for logging, auth, rate limiting

## How to Run:

1. The system automatically creates a default `config.json` if none exists
2. Set `RUST_LOG=debug` for detailed tracing
3. Run with `cargo run`

## Extension Points:

- **New Load Balancing Strategies**: Implement `LoadBalancingStrategy` trait
- **Additional Middleware**: Add new middleware functions to the chain
- **Health Checks**: Framework ready for backend health monitoring
- **Metrics**: Tracing spans can be connected to metrics systems

The solution is minimal but architected for easy extension while maintaining clean separation of concerns.

// src/main.rs
use std::net::SocketAddr;
use tower::make::Shared;
use hyper::{service::service_fn, Body, Request, Response, Server};
use tracing::{info, warn};

mod config;
mod load_balancer;
mod middleware;

use config::Config;
use load_balancer::LoadBalancer;
use middleware::MiddlewareChain;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Initialize tracing
    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
        .init();

    // Load configuration
    let config = Config::load("config.json").await?;
    info!("Loaded configuration with {} routes", config.routes.len());

    // Create load balancer
    let load_balancer = LoadBalancer::new(config.clone());

    // Create middleware chain
    let middleware_chain = MiddlewareChain::new(load_balancer);

    let make_service = Shared::new(service_fn(move |req| {
        let middleware = middleware_chain.clone();
        async move {
            middleware.handle(req).await
        }
    }));

    let addr: SocketAddr = config.server.bind_address.parse()?;
    info!("Starting load balancer on {}", addr);

    let server = Server::bind(&addr).serve(make_service);

    if let Err(e) = server.await {
        warn!("Server error: {}", e);
    }

    Ok(())
}

// src/config.rs
use serde::{Deserialize, Serialize};
use std::collections::HashMap;
use tokio::fs;
use tracing::{info, error};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Config {
    pub server: ServerConfig,
    pub routes: HashMap<String, RouteConfig>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ServerConfig {
    pub bind_address: String,
    pub timeout_seconds: Option<u64>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RouteConfig {
    pub path: String,
    pub backends: Vec<Backend>,
    pub load_balancing: LoadBalancingConfig,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Backend {
    pub url: String,
    pub weight: Option<u32>,
    pub health_check_path: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LoadBalancingConfig {
    pub strategy: String, // "round_robin", "weighted_round_robin", etc.
}

impl Config {
    pub async fn load(path: &str) -> Result<Self, Box<dyn std::error::Error>> {
        match fs::read_to_string(path).await {
            Ok(content) => {
                let config: Config = serde_json::from_str(&content)?;
                info!("Successfully loaded configuration from {}", path);
                Ok(config)
            },
            Err(e) => {
                error!("Failed to read config file {}: {}", path, e);
                info!("Creating default configuration");
                let default_config = Self::default();
                let json = serde_json::to_string_pretty(&default_config)?;
                fs::write(path, json).await?;
                info!("Default configuration written to {}", path);
                Ok(default_config)
            }
        }
    }
}

impl Default for Config {
    fn default() -> Self {
        let mut routes = HashMap::new();

        routes.insert("api".to_string(), RouteConfig {
            path: "/api".to_string(),
            backends: vec![
                Backend {
                    url: "http://127.0.0.1:8001".to_string(),
                    weight: Some(1),
                    health_check_path: Some("/health".to_string()),
                },
                Backend {
                    url: "http://127.0.0.1:8002".to_string(),
                    weight: Some(1),
                    health_check_path: Some("/health".to_string()),
                },
            ],
            load_balancing: LoadBalancingConfig {
                strategy: "round_robin".to_string(),
            },
        });

        routes.insert("default".to_string(), RouteConfig {
            path: "/".to_string(),
            backends: vec![
                Backend {
                    url: "http://127.0.0.1:8080".to_string(),
                    weight: Some(1),
                    health_check_path: None,
                },
            ],
            load_balancing: LoadBalancingConfig {
                strategy: "round_robin".to_string(),
            },
        });

        Config {
            server: ServerConfig {
                bind_address: "127.0.0.1:3000".to_string(),
                timeout_seconds: Some(30),
            },
            routes,
        }
    }
}

// src/load_balancer.rs
use std::sync::{Arc, Mutex};
use std::collections::HashMap;
use hyper::{Body, Client, Request, Response, StatusCode, Uri};
use tracing::{info, warn, error, debug};

use crate::config::{Config, RouteConfig, Backend};

pub trait LoadBalancingStrategy: Send + Sync {
    fn select_backend(&self, backends: &[Backend]) -> Option<&Backend>;
    fn name(&self) -> &'static str;
}

#[derive(Debug)]
pub struct RoundRobin {
    counter: Arc<Mutex<usize>>,
}

impl RoundRobin {
    pub fn new() -> Self {
        Self {
            counter: Arc::new(Mutex::new(0)),
        }
    }
}

impl LoadBalancingStrategy for RoundRobin {
    fn select_backend(&self, backends: &[Backend]) -> Option<&Backend> {
        if backends.is_empty() {
            return None;
        }

        let mut counter = self.counter.lock().unwrap();
        let index = *counter % backends.len();
        *counter = (*counter + 1) % backends.len();

        debug!("Round robin selected backend index: {}", index);
        backends.get(index)
    }

    fn name(&self) -> &'static str {
        "round_robin"
    }
}

#[derive(Clone)]
pub struct LoadBalancer {
    config: Config,
    strategies: Arc<HashMap<String, Arc<dyn LoadBalancingStrategy>>>,
    client: Client<hyper::client::HttpConnector>,
}

impl LoadBalancer {
    pub fn new(config: Config) -> Self {
        let mut strategies: HashMap<String, Arc<dyn LoadBalancingStrategy>> = HashMap::new();
        strategies.insert("round_robin".to_string(), Arc::new(RoundRobin::new()));

        Self {
            config,
            strategies: Arc::new(strategies),
            client: Client::new(),
        }
    }

    pub async fn handle_request(&self, mut req: Request<Body>) -> Result<Response<Body>, hyper::Error> {
        let path = req.uri().path();
        let route_config = self.find_matching_route(path);

        match route_config {
            Some(route) => {
                info!("Matched route: {} for path: {}", route.path, path);
                self.proxy_request(req, route).await
            },
            None => {
                warn!("No matching route found for path: {}", path);
                Ok(Response::builder()
                    .status(StatusCode::NOT_FOUND)
                    .body(Body::from("Route not found"))
                    .unwrap())
            }
        }
    }

    fn find_matching_route(&self, path: &str) -> Option<&RouteConfig> {
        // Find the most specific matching route
        self.config.routes.values()
            .filter(|route| path.starts_with(&route.path))
            .max_by_key(|route| route.path.len())
    }

    async fn proxy_request(&self, mut req: Request<Body>, route: &RouteConfig) -> Result<Response<Body>, hyper::Error> {
        let strategy = self.strategies.get(&route.load_balancing.strategy)
            .unwrap_or_else(|| self.strategies.get("round_robin").unwrap());

        let backend = match strategy.select_backend(&route.backends) {
            Some(backend) => backend,
            None => {
                error!("No available backends for route: {}", route.path);
                return Ok(Response::builder()
                    .status(StatusCode::SERVICE_UNAVAILABLE)
                    .body(Body::from("No available backends"))
                    .unwrap());
            }
        };

        info!("Proxying request to backend: {}", backend.url);

        // Modify the request URI to point to the selected backend
        let backend_uri: Uri = format!("{}{}", backend.url, req.uri().path_and_query().map(|p| p.as_str()).unwrap_or(""))
            .parse()
            .map_err(|e| {
                error!("Failed to parse backend URI: {}", e);
                hyper::Error::from(hyper::http::Error::from(e))
            })?;

        *req.uri_mut() = backend_uri;

        // Remove hop-by-hop headers
        req.headers_mut().remove("connection");
        req.headers_mut().remove("proxy-connection");
        req.headers_mut().remove("te");
        req.headers_mut().remove("trailer");
        req.headers_mut().remove("upgrade");

        match self.client.request(req).await {
            Ok(response) => {
                debug!("Successfully proxied request, status: {}", response.status());
                Ok(response)
            },
            Err(e) => {
                error!("Failed to proxy request to {}: {}", backend.url, e);
                Ok(Response::builder()
                    .status(StatusCode::BAD_GATEWAY)
                    .body(Body::from("Backend unavailable"))
                    .unwrap())
            }
        }
    }

    pub fn add_strategy(&mut self, name: String, strategy: Arc<dyn LoadBalancingStrategy>) {
        Arc::get_mut(&mut self.strategies)
            .unwrap()
            .insert(name, strategy);
    }
}

// src/middleware.rs
use hyper::{Body, Request, Response};
use tracing::{info, debug, Span};
use uuid::Uuid;
use std::time::Instant;

use crate::load_balancer::LoadBalancer;

#[derive(Clone)]
pub struct MiddlewareChain {
    load_balancer: LoadBalancer,
}

impl MiddlewareChain {
    pub fn new(load_balancer: LoadBalancer) -> Self {
        Self { load_balancer }
    }

    pub async fn handle(&self, req: Request<Body>) -> Result<Response<Body>, hyper::Error> {
        // Generate request ID for tracing
        let request_id = Uuid::new_v4().to_string();

        // Create a span for this request
        let span = tracing::info_span!(
            "http_request",
            request_id = %request_id,
            method = %req.method(),
            path = %req.uri().path(),
            remote_addr = ?req.headers().get("x-forwarded-for").or_else(|| req.headers().get("x-real-ip"))
        );

        async move {
            let start_time = Instant::now();

            info!("Processing request");
            debug!("Request headers: {:?}", req.headers());

            // Apply logging middleware
            let response = self.logging_middleware(req).await;

            let duration = start_time.elapsed();
            match &response {
                Ok(res) => {
                    info!(
                        status = %res.status(),
                        duration_ms = %duration.as_millis(),
                        "Request completed"
                    );
                },
                Err(e) => {
                    info!(
                        error = %e,
                        duration_ms = %duration.as_millis(),
                        "Request failed"
                    );
                }
            }

            response
        }.instrument(span).await
    }

    async fn logging_middleware(&self, req: Request<Body>) -> Result<Response<Body>, hyper::Error> {
        let method = req.method().clone();
        let path = req.uri().path().to_string();
        let query = req.uri().query().map(|q| q.to_string());

        info!(
            method = %method,
            path = %path,
            query = ?query,
            "Incoming request"
        );

        // Apply rate limiting middleware (placeholder for future implementation)
        self.rate_limiting_middleware(req).await
    }

    async fn rate_limiting_middleware(&self, req: Request<Body>) -> Result<Response<Body>, hyper::Error> {
        // Placeholder for rate limiting - currently just passes through
        debug!("Rate limiting check passed");

        // Apply authentication middleware (placeholder for future implementation)
        self.auth_middleware(req).await
    }

    async fn auth_middleware(&self, req: Request<Body>) -> Result<Response<Body>, hyper::Error> {
        // Placeholder for authentication - currently just passes through
        debug!("Authentication check passed");

        // Forward to load balancer
        self.load_balancer.handle_request(req).await
    }
}
