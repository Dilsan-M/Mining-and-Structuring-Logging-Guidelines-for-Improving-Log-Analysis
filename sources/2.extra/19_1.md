In the past we were relying on console printouts and unserialised log files to log the actions of our systems. As the
complexity of the system increased, so did the amount and complexity of the logged data, and the previous approach was
not feasible anymore.

<how_to_log>Fortunately, there is already solutions like [MCAP](mcap.md) and [Foxglove](foxglove.md), that combined
with [ProtoBuf](protobuf.md) allows us to make smaller sized logs with better traceability.</how_to_log>

<how_to_log>Python packages like [mcap-protobuf-support](https://pypi.org/project/mcap-protobuf-support/)
and [foxglove-schemas-protobuf](https://pypi.org/project/foxglove-schemas-protobuf/) are nice implementations to achieve
this.</how_to_log>

The goal of this package is...

- <how_to_log>to create a logger handler that leverages the existing MCAP and Foxglove packages</how_to_log>
- <how_to_log>to leverage the configurability of Python</how_to_log>
- <how_to_log>to provide a plugin for standard Python loging</how_to_log>
