## Overview

The SMTP-POP3 Mailing Server is a complete email system implementation that provides both SMTP (Simple Mail Transfer Protocol) and POP3 (Post Office Protocol 3) services. The system consists of three main components:

- **SMTP Server** (`mailserver_smtp.py`): Handles email sending and delivery
- **POP3 Server** (`pop_server.py`): Manages email retrieval and mailbox operations
- **Mail Client** (`mail_client.py`): Provides user interface for email operations

### Key Features

- Multi-threaded server architecture
- RFC-compliant protocol implementations
- Thread-safe mailbox operations
- Structured logging and error handling
- User authentication with password hashing
- Message format validation

## API Reference

### Core Classes

#### ConfigWrapper

Manages application configuration and provides type-safe access to settings.

```python
class ConfigWrapper:
    def __init__(self, logger: BoundLogger, file_name: str)
```

**Methods:**

- `get_host() -> str`: Returns server host address
- `get_max_size_package_tcp() -> int`: Returns maximum TCP package size
- `get_mail_client_actions_as_list_of_strings() -> List[str]`: Returns available client actions
- `get_message_format() -> str`: Returns expected message format
- `get_stopping_character() -> str`: Returns message termination character

#### MessageWrapper

Handles email message parsing, validation, and formatting.

```python
class MessageWrapper(logger: BoundLogger, config: ConfigWrapper, message: str)
```

**Methods:**

- `verify_format() -> bool`: Validates message format against RFC 5322
- `get_from() -> str`: Extracts sender email address
- `get_to() -> str`: Extracts recipient email address
- `get_subject() -> str`: Extracts message subject
- `get_message_body() -> str`: Extracts message body content

#### Action (Abstract Base Class)

Base class for all client actions.

```python
class Action(ABC):
    def __init__(self, logger: BoundLogger, config: ConfigWrapper, 
                 ip_address, SMTP_port, POP3_port, username)
    
    @abstractmethod
    def action(self): pass
```

## Protocol Specifications

### SMTP Protocol Implementation

The SMTP server implements RFC 5321 with the following command sequence:

1. **HELO** - Server identification
2. **MAIL FROM** - Sender specification
3. **RCPT TO** - Recipient specification
4. **DATA** - Message content transmission
5. **QUIT** - Connection termination

**Response Codes:**
- `250 OK` - Command successful
- `354` - Start mail input
- `221` - Service closing transmission channel
- `554` - Transaction failed

### POP3 Protocol Implementation

The POP3 server implements RFC 1939 with state-based operation:

**States:**
- **AUTHORIZATION** - User authentication required
- **TRANSACTION** - Mailbox operations allowed
- **UPDATE** - Cleanup and connection termination

**Commands:**
- `USER` - Username authentication
- `PASS` - Password authentication
- `STAT` - Mailbox statistics
- `LIST` - Message listing
- `RETR` - Message retrieval
- `DELE` - Message deletion
- `QUIT` - Session termination

**Response Codes:**
- `+OK` - Command successful
- `-ERR` - Command failed

## Troubleshooting

### Common Issues

#### Connection Refused
**Symptoms**: Client cannot connect to server
**Causes**: Server not running, wrong port, firewall blocking
**Solutions**: 
1. Verify server is running
2. Check port configuration
3. Verify firewall settings

#### Authentication Failures
**Symptoms**: "Invalid username" or "Invalid password" errors
**Causes**: Incorrect credentials, user not in userinfo.txt
**Solutions**:
1. Verify username format
2. Check userinfo.txt file
3. Ensure password is correctly hashed

#### Message Format Errors
**Symptoms**: "Incorrect format" errors during message sending
**Causes**: Invalid email format, missing required fields
**Solutions**:
1. Follow RFC 5322 message format
2. Include all required headers (From, To, Subject)
3. End message with single period on new line
