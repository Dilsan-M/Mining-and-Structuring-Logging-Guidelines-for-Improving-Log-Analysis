# TalentMatch Logging Guide

* <how_to_log>TalentMatch uses the `java.util.logging` package for logging.</how_to_log>
* <how_to_log>The `LogsCenter` class is used to manage the logging levels and logging destinations.</how_to_log>
* <how_to_log>The `Logger` for a class can be obtained using `LogsCenter.getLogger(Class)` which will log messages according to the specified logging level.</how_to_log>
* <where_to_log>Log messages are output through the console and to a `.log` file.</where_to_log>
* <log_verbosity>The output logging level can be controlled using the `logLevel` setting in the configuration file (See the [Configuration guide](Configuration.md) section).</log_verbosity>
* <log_verbosity>**When choosing a level for a log message**, follow the conventions given in [_[se-edu/guides] Java: Logging conventions_](https://se-education.org/guides/conventions/java/logging.html).</log_verbosity>

## TalentMatch-Specific Logging

### Key Components to Log

TalentMatch logs important events in these key components:

* <what_to_log>**ModelManager**: Log changes to application data (persons, jobs, applications)</what_to_log>
* <what_to_log>**LogicManager**: Log command execution and parsing</what_to_log>
* <what_to_log>**StorageManager**: Log data saving and loading operations</what_to_log>
* <what_to_log>**UiManager**: Log UI initialization and updates</what_to_log>

### Logging Levels for TalentMatch Components

* <log_verbosity>**SEVERE**: System failures, data corruption, or critical errors that prevent core functionality</log_verbosity>
* <log_verbosity>**WARNING**: Potential issues with data integrity or user errors</log_verbosity>
* <what_to_log><log_verbosity>**INFO**: Major user operations (add/edit/delete persons, jobs, or applications)</log_verbosity></what_to_log>
* <what_to_log><log_verbosity>**FINE**: Detailed information about command execution and data processing</log_verbosity></what_to_log>
* <log_verbosity>**FINER/FINEST**: Highly detailed debugging information for troubleshooting</log_verbosity>

### Debugging TalentMatch

When troubleshooting issues with TalentMatch:

1. <log_verbosity>Set the logging level to `FINE` or `FINER` in `config.json` to see detailed execution flow</log_verbosity>
2. <where_to_log>Check the `.log` file for error stacktraces and warnings</where_to_log>
3. <where_to_log>Pay special attention to logs from the component where issues are suspected</where_to_log>
4. <what_to_log>Look for errors in job-application relationship management and view state transitions</what_to_log>

Logs are especially useful for diagnosing issues related to:
* Command parsing errors
* Data persistence problems
* Application status transitions
* Relationship management between persons, jobs, and applications
