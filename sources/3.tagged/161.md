# 🚀 Smart Document Analyzer - Demo Guide

## Quick Demo

Your Smart Document Analyzer is now running! Here's how to experience its capabilities:

### 🌐 Web Interface (Recommended)
1. **Open your browser** and go to: http://localhost:8080
2. **Upload a document** by clicking "Choose File" or dragging and dropping
3. **Watch the magic happen** as the AI analyzes your document in real-time
4. **View the results** including summary, sentiment, classification, and tags

### 🔧 API Testing
Run the automated test script:
```bash
./test-api.sh
```

Or test manually:
```bash
# Upload a document
curl -X POST -F "file=@sample-documents/test-document.txt" http://localhost:8080/api/documents/upload

# Get all documents
curl http://localhost:8080/api/documents

# Check system stats
curl http://localhost:8080/api/documents/stats
```

## 🔧 Customization Options

### Add OpenAI Integration
```bash
export OPENAI_API_KEY=your_api_key_here
# Restart the application to use real AI features
```

### Modify Upload Settings
Edit `application.yml`:
```yaml
spring:
  servlet:
    multipart:
      max-file-size: 20MB  # Increase file size limit
```

### Custom Upload Directory
```bash
export UPLOAD_DIR=/custom/path/uploads
```
