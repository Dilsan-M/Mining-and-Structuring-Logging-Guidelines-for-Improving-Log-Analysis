# API Specification

## Service Overview
- The unified FastAPI app (`uvicorn app:app`) exposes the research generator, vector search API, and HTML frontend under one base URL.
- Frontend pages render from `GET /` and `POST /render`, with static assets served at `/static/*`.
- JSON endpoints follow FastAPI defaults; internal failures return `500` and Gemini errors surface as `502`.

## Authentication
- Research and search endpoints require a Gemini API key. Provide it via environment (`GEMINI_API_KEY` or `GOOGLE_API_KEY`) or pass `api_key` in the search payload.
- <how_to_log>Store keys in local `.env` files and strip them from shared logs.</how_to_log>

## Endpoints

### GET /
- **Description:** Returns the book viewer HTML. If `frontend/response.txt` holds a valid `SearchResult`, the page auto-renders it; otherwise a placeholder message appears.
- **Response:** `text/html`

### POST /render
- **Description:** Renders the book viewer for an on-demand `SearchResult`.
- **Request Body:** `SearchResult` JSON (`title`, `author`, optional `raw_text`, structured `sections`, citation spans, `sources`).
- **Response:** `text/html`

### GET /health
- **Description:** Research service health probe.
- **Response:** `{"status": "ok"}`

### POST /research
- **Description:** Generates a grounded book report via Gemini.
- **Request Body:** `{ "title": str, "author": str, "focus_areas": [str]|null, "language": "ko"|... }`
- **Response:** JSON with `title`, `author`, `raw_text`, structured `sections`, `citations`, and `sources`.
- **Errors:** `502` (Gemini), `422` (validation).

### GET /healthz
- **Description:** Vector search health probe.
- **Response:** `{"status": "ok"}`

### POST /search
- **Description:** Returns top-N search hits from the on-disk embedding index.
- **Core Fields:** `npz` (required path), `query`, `top_k` (default 5), `meta` (CSV for title dedup), `index_only`, `include_score`, `include_rank`, `source_csv` (plus `source_id_col` / `source_sep` / `source_encoding`), `json_cols`, `randomize`, `tau`, `seed`, `max_text_chars`.
- **Response:** JSON with query metadata (`top_k`, `unique_returned`, `dedup_by_title`, `randomize`, `tau`, `seed`, index paths) plus a `results` array.
- **Result Objects:** Always include `id`; may add `_score`, `_rank`, selected CSV columns, or truncated text depending on flags.
- **Notes:** Rate limited to `RATE_LIMIT_PER_MINUTE` (default 100); limit breaches return `429` with `Retry-After`.

## Error & Logging Conventions
- Validation errors emit `422` with field-level details.
- <how_to_log>CSV and index read failures return `400` for missing files or `500` for parsing problems, with logs tagged by path.</how_to_log>
