* <how_to_log>We are using `java.util.logging` package for logging.</how_to_log>
* <how_to_log>The `LogsCenter` class is used to manage the logging levels and logging destinations.</how_to_log>
*  <how_to_log>The `Logger` for a class can be obtained using `LogsCenter.getLogger(Class)` which will log messages according to the specified logging level.</how_to_log>
*  <where_to_log>Log messages are output through the console and to a `.log` file.</where_to_log>
*  <how_to_log><log_verbosity>The output logging level can be controlled using the `logLevel` setting in the configuration file (See the [Configuration guide](Configuration.md) section).</log_verbosity></how_to_log>
* <log_verbosity>**When choosing a level for a log message**, follow the conventions given in [_[se-edu/guides] Java: Logging conventions_](https://se-education.org/guides/conventions/java/logging.html).</log_verbosity>
